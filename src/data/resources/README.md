# دليل موارد التعلّم العربية (`resources.json`)

القائمة المضمّنة في الإضافة لدليل الموارد (`T-9.5`، `F-H5`): تعمل دون إنترنت، ولا تُسحب قوائم خارجية إليها تلقائيًا. ما يضيفه المستخدم أو
يعدّله أو يخفيه يُحفظ محليًا في التخزين (سجل لكل مورد باسم `resources.item.<id>`) فوقها ولا يمسّ هذا الملف.

## الصيغة (`format: "mijhar-resources"`، `schemaVersion: 1`)

| الحقل | المعنى |
| :--- | :--- |
| `categories[]` | `id` و`title`: تصنيفات العرض. |
| `resources[].id` | معرّف فريد بأحرف إنجليزية صغيرة وأرقام وشرطات (`^[a-z0-9][a-z0-9-]{0,63}$`). |
| `resources[].url` | رابط `https` بلا بيانات اعتماد. الفحص الآلي لروابط `github.com/<owner>/<repo>` وحدها. |
| `resources[].lastVerified` | تاريخ آخر تحقق `YYYY-MM-DD` (أو `null` لما لم يُتحقق منه). |
| `resources[].status` | `active` (غير مؤرشف) أو `archived` أو `unverified` أو `unreachable` (تعذّر الوصول عند آخر فحص؛ لا يعني الحذف). |
| `resources[].lastPush`، `license` | آخر دفع وترخيص المستودع عند آخر فحص GitHub. |
| `resources[].source` | كيف تُحقق من المورد (يظهر للمستخدم تحته). |
| `resources[].origin` | `builtin` هنا دائمًا؛ وما يضيفه المستخدم `user`. |
| `review` | حالة مراجعة القائمة (انظر أدناه). |

المدقق في `src/modules/h/resources/model.ts` (`parseResourceFile` و`resourceProblems`)، وهو نفسه مدقق استيراد المستخدم، والاختبار
`tests/modules/h/resources/model.test.ts` يفرض على هذا الملف: صلاحية كل عنصر، وفرادة المعرّفات والروابط، وتصنيفًا معرَّفًا، وتاريخ تحقق لا
في المستقبل، ومصدر تحقق موثقًا، وأن كل رابط مستودع `github.com`.

## القائمة الأولى: مراجعة آلية تنتظر مراجعة بشرية

تقول الخطة (`T-9.5`) إن محتويات القائمة الأولى «تُحدَّد بمراجعة بشرية موثقة المصدر قبل التضمين». ما في الملف اقتراح أولي اختاره منفّذ المرحلة
(نموذج) ودقّقه آليًا في 2026-10-23، ولم يراجعه إنسان بعد (`review.status: "automated-pending-owner-review"`):

1. **الاختيار:** من بحث GitHub REST العام (مواضيع `arabic` و`arabic-nlp` و`arabic-fonts`، وعبارات «awesome arabic» و«arabic programming resources»)
   بما يتعلق بالتعلّم والمراجع العربية، مع استبعاد قوائم أشخاص (حسابات مطورين) وما رُدّد إلى نسخة متفرعة مؤرشفة.
2. **التحقق لكل مورد:** `GET /repos/<owner>/<repo>` بلا مصادقة: وجود المستودع، وعدم أرشفته، والترخيص، وآخر دفع. وحيث ادُّعي محتوى عربي في الوصف حُقق
   منه: `GET /repos/github/opensource.guide/contents/_articles/ar` (200) و`GET /repos/EbookFoundation/free-programming-books/contents/books`
   (يضم `free-programming-books-ar.md`) وREADME العربي لـ`trekhleb/javascript-algorithms` (قياس `evidence/T-0.4`).
3. **ما لم يُفحص:** جودة المحتوى وملاءمته لمستوى المتعلّم، وحداثة ما في داخل كل مورد. «نشط» يعني غير مؤرشف على GitHub لا حديث العمل
   (`lastPush` يُظهر آخر دفع).

يراجع المالك الاختيار ثم يغيّر `review.status` إلى حالة معتمدة بتاريخها قبل الإصدار.

## التحديث

لا تحديث تلقائي. يضغط المستخدم «تحقق الآن» أو «تحقق من روابط GitHub المعروضة» (حتى 20 طلبًا في النقرة) فيصدر `GET` واحد إلى `api.github.com` لكل
مستودع بالصلاحية الاختيارية؛ والروابط الخارجية لا طلب لها وتُراجع يدويًا (زر «سجّل المراجعة»). مستودع نُقل أو أُعيدت تسميته يُقترح رابطه الجديد
ولا يُطبَّق دون تأكيد.
