# عينات قوالب المستودعات (T-7.2 — حارس «القالب أولًا»)

عينات محلية لاختبار `TEST-WRITE-02` (`AC-F2`)، مكتوبة لمرحلة `MJ13`؛ **ليست لقطات حية** من github.com (صفحات البلاغ الجديد بنموذج تتطلب تسجيل دخول، وهو ما أقرّه `evidence/T-0.4/report.md`). تقرّب بنية الحقول
(تسميات وإلزامي وأنواع الحقول: نصي ومنطقة نص وقائمة منسدلة ومربعات اختيار) ولا تحاكي كل سلوك الصفحة الحية، فيبقى فحص يدوي على صفحات حية حيث تتوفر.

| الملف | ما فيه |
| :--- | :--- |
| `bug_report.yml` | تعريف Issue Form كما يكتبه صاحب المستودع (مرجع للحقول في `issue-form.html`) |
| `issue-form.html` | صفحة بلاغ جديد (`/issues/new?template=bug_report.yml`) بنموذج: عنوان، وحقل نصي إلزامي، ومنطقتا نص إلزاميتان، وقائمة منسدلة، ومربع موافقة إلزامي، وزر إرسال حقيقي |
| `bug_report.md` | قالب بلاغ Markdown (ترويسات وتعليقات إرشاد) |
| `PULL_REQUEST_TEMPLATE.md` | قالب طلب دمج (ترويسات وقوائم تحقق وتعليقات) |
| `markdown-template.html` | صفحة مقارنة/طلب دمج جديد بحقل وصف يُملأ بالقالب في الاختبار |
| `unknown-template.html` | صفحة بلاغ جديد بنموذج حقوله بلا تسميات يُعتمد عليها: هيكل غير معروف |
| `plain-issue.html` | صفحة بلاغ جديد عادية (عنوان ووصف وقوائم جانبية) بلا قالب |

كل نموذج فيها بزر إرسال حقيقي (`type=submit`) ليُقاس أن المساعد لا ينقر عليه ولا يرسل النموذج.
