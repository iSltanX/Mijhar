النَّصُّ الأَوَّلُ

كَتَبَ المُطَوِّرُ الشِّيفْرَةَ بِعِنَايَةٍ ثُمَّ رَاجَعَهَا الفَرِيقُ.

بَدَأْنَا التَّجْرِبَةَ بِتَشْغِيلِ npm install ثُمَّ زُرْنَا الدَّلِيلَ الرَّسْمِيَّ لِلْمَزِيدِ.

  • عُنْصُرٌ أَوَّلُ فِي القَائِمَةِ
  • عُنْصُرٌ ثَانٍ مَعَ src/app/main.ts

فِقْرَةٌ أُخْرَى مَشْكُولَةٌ تُخْتَتَمُ بِهَا العَيِّنَةُ.

تَعْلِيقٌ مَشْكُولٌ سَيُحَرِّرُهُ صَاحِبُهُ.
