# عينات صفحات GitHub

صفحات GitHub عامة محفوظة وعينات مكتوبة، أُعدّت أولًا لتجارب الجدوى، وتستعملها اليوم اختبارات Vitest وفحوص المتصفح وسكربت اللقطات (`scripts/screenshots.mjs`). لا تدخل حزمة الإضافة.

| الملف | المصدر | الاستعمال |
| :--- | :--- | :--- |
| `gh-*.html` | صفحات GitHub عامة حقيقية بعد اكتمال عرضها بلا تسجيل دخول، محفوظة بـ`scripts/spikes/t01-capture.mjs` (في تاريخ Git). حُذفت السكربتات وبيانات JSON المضمّنة ورموز الجلسة (`csrf-token` وما يشبهها)، وبقيت روابط أنماط GitHub. المصادر وأوقات الحفظ في `samples.json` | مصفوفة المحددات وسلوك الاتجاه (`AC-S1.1`)، وخط الأساس (`AC-S1.4`) |
| `fixture-diacritics-live.html` | مكتوبة لهذه التجربة: تعليقات مشكولة بنية `.markdown-body`، وكائن `GH` يحاكي كتابات GitHub في العقد النصية (تحديث، استبدال، فصل) | الحالات `TEST-RTL-05A..05G` (`AC-S1.3`) |
| `fixture-editor.html` | مكتوبة لهذه التجربة: `textarea` بحجم ثابت | تبديل `dir` في طبقة المتصفح (`AC-S1.2`) |
| `fixture-50-comments.html` | خمسون تعليقًا أجسامها من تعليقات حقيقية في `gh-issue-etos-1` و`gh-issue-winscreen-1` و`gh-pr-watad-80`، تُكرَّر بالترتيب | `PB-02` (`AC-S1.4`) |

النصوص في عينات `gh-*` ملك أصحابها على GitHub، وحُفظت مرجعًا للقياس على مستودعات عامة.
