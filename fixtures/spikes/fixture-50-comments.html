الهدف

اتصال Local Debug (التشخيص المتقدم / Remote File Access) ينقطع لما التطبيق يطلع للخلفية أو حتى عند .inactive (مركز التحكم)، وما يرجع يتصل تلقائياً.

السبب

ETOS LLM Studio/ETOS LLM Studio iOS App/Views/LocalDebugView.swift (حوالي السطر 253):

.onChange(of: scenePhase) { _, newPhase in
    if newPhase != .active && server.isRunning { disconnectServer() }
}

disconnectServer() → server.disconnect() → stopAutoReconnect() (LocalDebugServerConnection.swift:160) فيمسح هدف إعادة الاتصال. نفس الشي في Watch LocalDebugView سطر 72.

المطلوب

  1. في LocalDebugView.swift (iOS و Watch): تجاهل .inactive. عند .background لا تفصل؛ ابدأ ApplicationBackgroundTaskLease("local-debug") وعند انتهائه استدعِ server.suspendForBackground(). عند .active أنهِ الـlease واستدعِ server.resumeIfNeeded(). زر Disconnect فقط يستدعي stopAutoReconnect().
  2. في LocalDebugServerConnection.swift: أضف suspendForBackground() (يلغي WebSocket/مؤقت HTTP/الجلسة مع إبقاء reconnectTarget وautoReconnectEnabled) وresumeIfNeeded() (إذا autoReconnectEnabled && !isRunning صفّر reconnectAttempt واتصل فوراً عبر مسار إعادة الاتصال الموجود).
  3. (iOS فقط) خيار جديد في AppConfig افتراضياً مغلق: "ابقَ متصلاً في الخلفية" — LocalDebugKeepAlive.swift يشغّل AVAudioSession بفئة .playback مع .mixWithOthers ويكرر buffer صامت بـ AVAudioEngine طول ما الاتصال شغال والخيار مفعّل، ويوقف عند الفصل. وضع audio موجود أصلاً في iOSInfo.plist. أضف مفتاح الإعداد في صفحة التشخيص المتقدم مع نصوص عربي/إنجليزي/صيني.
  4. (اختياري) إشعار محلي إذا فشل الاتصال بعد نفاد المحاولات.

  2. ابحث عن المهارة المناسبة، ثم افتح مستودعها الأصلي واقرأ SKILL.md والمتطلبات. تحقّق من name وdescription ومن الموارد المشار إليها. رابط صفحة توثيق أو صفحة نتائج بحث ليس حزمة مهارة. احتفظ برابط المصدر والنسخة/commit التي راجعتها إن توفر.

  3. المسار المدمج في واجهة iOS:
    الإعدادات ← مهارات الوكيل ← استيراد من جيثب ← عنوان URL للمستودع ← استيراد.
    يدعم رابط المجلد /tree/<branch>/<path>. عند وجود عدة مهارات في المستودع، استخدم رابط مجلد المهارة المحدد. رابط SKILL.md المباشر في خانة الروابط يجلب الملف فقط، وليس موارده. توجد أيضًا خيارات لصق SKILL.md، واستيراد حزمة محلية، واستيراد رابط مباشر لـ SKILL.md أو ZIP. هذه خطوات واجهة للمستخدم ما لم توجد لديك أداة فعلية للتحكم بها؛ لا تدّعِ الضغط على أزرار لم تضغطها.

  4. عند وجود تفويض بالتنزيل وأدوات ملفات مناسبة، يمكن تجهيز المهارة يدويًا:

  • افحص مكان مكتبة Skills الحقيقية أولًا. أدوات sandbox قد تشير إلى مساحة عمل مختارة بدل Documents؛ وكتابة الملفات في Linux أو مجلد عمل عشوائي لا تعني استيرادها إلى مكتبة التطبيق.

  • لا تستبدل مهارة موجودة بصمت، ولا تنفذ أوامر تثبيت مأخوذة من README لمجرد تنزيل التعليمات.
