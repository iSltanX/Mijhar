# لقطات مِجهَر

> **فارغ حتى `MJ26`.** لا يوضع هنا إلا لقطة حقيقية من النسخة المرشحة للإصدار بعد دمجها وعملها. تصاميم Figma ليست لقطات، ولا تُصدَّر إلى هذا المجلد.

## الملفات

لكل لقطة صيغتان بمقاس 1280×800، تُصدَّران من قوالب صفحة «مجهر — مواد الإصدار والمتاجر» في Figma بعد وضع اللقطة الحقيقية فيها:

| الصيغة | الاسم | المتجر |
| :--- | :--- | :--- |
| بشريط عنوان | `NN-name--captioned--light.png` | Chrome Web Store (حتى 5) وMicrosoft Edge Add-ons (حتى 6) |
| بلا نص | `NN-name--clean--light.png` | Firefox Add-ons، والتعليق في نص المتجر |
| للوضع الداكن | `…--dark.png` | README وصفحات الموقع (`<picture>`) |

والأسماء والتعليقات وترتيبها في [`../listings/store-listing.ar.md`](../listings/store-listing.ar.md#تعليقات-اللقطات).

## شروط الالتقاط

- مستودع تجريبي **عام**، بلا بيانات مستودع خاص ولا رمز ولا مفتاح ولا اسم مستخدم حقيقي ولا إشعارات شخصية.
- نافذة المتصفح بالعرض الذي يعطي 1280×800 بلا تحجيم، وواجهة مِجهَر بالعربية، والوضعان الفاتح والداكن.
- لا تُعدَّل اللقطة إلا بالقص؛ لا تُضاف عناصر لم تعرضها الإضافة.
- يُسجَّل لكل لقطة في `evidence/T-10.2/` المتصفح وإصداره والتزام البناء وتاريخ الالتقاط.

هذا المجلد مستثنى صراحةً في `.gitignore` من قاعدة `screenshots/` العامة.
