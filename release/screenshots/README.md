# لقطات مِجهَر

لقطات حقيقية من الإصدار 1.0.0: ما تعرضه الحزمة المبنية `dist/chromium` في Chrome، بلا أي تعديل. تصاميم Figma ليست لقطات، ولا يوضع هنا إلا ما التقطه المتصفح.

## الملفات

ست لقطات بترتيب العرض (`01-reading` إلى `06-notes`)، وتعليقاتها وترتيبها في [`../listings/store-listing.ar.md`](../listings/store-listing.ar.md#تعليقات-اللقطات).

| الصيغة | الاسم | المقاس | المتجر |
| :--- | :--- | :--- | :--- |
| بشريط عنوان | `NN-name--captioned--light.png` | 1280×800 | Chrome Web Store (1 إلى 5) وMicrosoft Edge Add-ons (الست) |
| بلا نص | `NN-name--clean--light.png` | 1280×800 | Firefox Add-ons، والتعليق في وصف اللقطة |
| للوضع الداكن | `NN-name--clean--dark.png` | 1280×800 | README وصفحات الموقع (`<picture>`)، لا المتاجر |

- **الصيغتان الفاتحتان** مصدَّرتان من القوالب R-01 إلى R-12 في صفحة «مجهر — مواد الإصدار والمتاجر» في Figma بعد وضع اللقطة فيها: شريط العنوان (الشعار والتعليق) فوق لقطة 1280×688، أو اللقطة 1280×800 وحدها. وقُورن كل تصدير باللقطة الملتقطة بكسلًا بكسلًا فتطابقا.
- **الداكنة** لا قالب لها لأنها لا تُرفع إلى متجر: هي اللقطة الملتقطة نفسها.
- **الصيغة:** PNG بـ24 بت بلا قناة شفافية.

## كيف التُقطت

`npm run build && node scripts/screenshots.mjs --out <مجلد>` يحمّل `dist/chromium` في Chrome، ويفتح صفحات GitHub ويتفاعل معها بنقرات وضغطات فعلية، ثم يلتقط.

- **الصفحات:** بنية صفحات GitHub عامة محفوظة في `fixtures/` وأنماط GitHub الحقيقية من `github.githubassets.com`، بعد استبدال كل اسم مستخدم ومستودع وصورة شخصية ومحتوى بأسماء ومحتوى تجريبيين (`mijhar-demo/arabic-docs` و`demo-author` وغيرهما، ولا يقابل أي منها حسابًا في GitHub وقت الالتقاط). وتُخدم `github.com` محليًا، ويُحجب كل مضيف آخر.
- **ما يظهر من مِجهَر حقيقي:** لم يُعدَّل في واجهته شيء ولم يُضف إليها شيء. ولا رمز ولا مفتاح ولا بيانات خاصة في أي لقطة.
- **السجل:** لكل لقطة متصفحها وإصداره والتزام البناء ووقتها ومقاسها وصفحتها في [`../../evidence/T-10.2/screenshots-manifest.json`](../../evidence/T-10.2/screenshots-manifest.json).

هذا المجلد مستثنى صراحةً في `.gitignore` من قاعدة `screenshots/` العامة.
