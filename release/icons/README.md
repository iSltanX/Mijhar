# أيقونات مِجهَر

صادرات الأيقونة من المكوّن المعتمد `Brand/Extension icon` في Figma (صفحة «02 — المكوّنات»، وإعدادات تصديرها في القسم C من صفحة «مجهر — مواد الإصدار والمتاجر»)، المبني على حرف الميم في [`../brand/source/mm.svg`](../brand/source/mm.svg) (`AD-13`). لا يُرسم شعار جديد ولا يُعدَّل الحرف.

| الملف | المقاس | الاستعمال |
| :--- | :--- | :--- |
| `icon-16.png` | 16×16 | مفتاحا `icons` و`action` في المانيفست (شريط الأدوات وقائمة الإضافات). من النسخة المضبوطة لـ16 بكسل |
| `icon-32.png` | 32×32 | المانيفست (الشاشات عالية الكثافة، وWindows) |
| `icon-48.png` | 48×48 | المانيفست (صفحة إدارة الإضافات) |
| `icon-64.png` | 64×64 | المانيفست لـFirefox (AMO يوصي بـ32 و64) |
| `icon-96.png` | 96×96 | المانيفست لـFirefox (الشاشات عالية الكثافة) |
| `icon-128.png` | 128×128 | المانيفست، وأيقونة Chrome Web Store: الرسم 96×96 وحوله 16 شفافة، وأيقونة قسم «حول مِجهَر» في الإعدادات |
| `store-logo-300.png` | 300×300 | شعار Microsoft Edge Add-ons (1:1)، يُرفع في نموذج المتجر ولا يدخل الحزمة |

- **الصيغة:** PNG بقناة شفافية، والرسم يقرأ على الخلفيتين الفاتحة والداكنة.
- **في البناء:** ينسخ `scripts/build.mjs` الملفات الستة الأولى إلى `dist/<الهدف>/icons/`، ويقرؤها المانيفستان من هناك. هذا المجلد مصدرها الوحيد.
- **الأصل القابل للتحرير** في [`../brand/source/`](../brand/source/)، والصادرات هنا وحدها.
