# أيقونات مِجهَر

> **فارغ حتى `MJ26`.** تُصدَّر الأيقونات هنا من المكوّن المعتمد `Brand/Extension icon` في Figma (صفحة «02 — المكوّنات»)، المبني على حرف الميم في [`../brand/source/mm.svg`](../brand/source/mm.svg) (`AD-13`). لا يُرسم شعار جديد ولا يُعدَّل الحرف.

| الملف | المقاس | الاستعمال |
| :--- | :--- | :--- |
| `icon-16.png` | 16×16 | مفتاح `icons` في المانيفست (شريط الأدوات وقائمة الإضافات). من النسخة المضبوطة لـ16 بكسل في صفحة الهوية |
| `icon-32.png` | 32×32 | المانيفست (الشاشات عالية الكثافة، وWindows) |
| `icon-48.png` | 48×48 | المانيفست (صفحة إدارة الإضافات) |
| `icon-64.png` | 64×64 | المانيفست لـFirefox (AMO يوصي بـ32 و64) |
| `icon-96.png` | 96×96 | المانيفست لـFirefox (الشاشات عالية الكثافة) |
| `icon-128.png` | 128×128 | المانيفست، وأيقونة Chrome Web Store: الرسم 96×96 وحوله 16 شفافة |
| `store-logo-300.png` | 300×300 | شعار Microsoft Edge Add-ons (1:1) |

- **الصيغة:** PNG بقناة شفافية، والرسم يقرأ على الخلفيتين الفاتحة والداكنة (اختُبر في صفحة الهوية «06 — الرمز المختصر»).
- **الأصل القابل للتحرير** في [`../brand/source/`](../brand/source/)، والصادرات هنا وحدها.
- **في `MJ26`:** يُضاف مفتاح `icons` إلى `src/manifest/chromium.json` و`firefox.json` (المانيفست اليوم بلا أيقونات)، ويُنسخ ما يحتاجه البناء إلى الحزمة دون نقل هذا المجلد.
