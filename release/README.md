# مواد إصدار مِجهَر

هذا المجلد يجمع ما يُنشر مع مِجهَر خارج الشيفرة: الهوية والأيقونات، ولقطات الإضافة، وصور المتاجر والغلاف، ونصوص المتاجر ومواد التقديم، والحزم المبنية. لكل نوع مجلد واحد، ولا تُكرَّر مادة في مكانين.

## البنية

| المجلد | ما فيه | يُتتبَّع في git؟ | الآن |
| :--- | :--- | :--- | :--- |
| [`brand/source/`](brand/source/) | الأصول القابلة للتحرير: الشعار المعتمد `Mj2.svg` وحرف الأيقونة `mm.svg` | نعم | موجود |
| [`icons/`](icons/) | صادرات الأيقونة PNG بمقاساتها، من المكوّن المعتمد في Figma | نعم | مصدَّرة، وفي المانيفست والحزم |
| [`screenshots/`](screenshots/) | لقطات حقيقية من الحزمة المبنية، بالمقاسات التي تقبلها المتاجر | نعم | ست لقطات بصيغتين، وست داكنة لـREADME والموقع |
| [`artwork/`](artwork/) | صور المتاجر الترويجية وصورة رأس README | نعم | موجودة |
| [`listings/`](listings/) | نصوص المتاجر ومواد التقديم ومبررات الأذونات | نعم | مطابقة للحزم المبنية، وتُراجع مع نموذج كل متجر وقت التقديم |
| `packages/` | حزم الإضافة المبنية، مجلد لكل متصفح (`chromium/` و`firefox/` ومعها حزمة المصدر لـAMO)، و`SHA256SUMS` | **لا** (مولَّد) | يبنيه `node scripts/package.mjs` بعد `npm run build` |

**الوثائق العامة** (الخصوصية والمساعدة والصفحة التعريفية) مصدرها الواحد [`Docs/Site/`](../Docs/Site/)، ولا تُنسخ هنا. ومنها يكتب `node scripts/privacy.mjs` ملف `PRIVACY.md` في جذر المستودع، ويبقى `README.md` في الجذر.

**ليس هنا عمدًا:** مخرجات البناء (`dist/`)، والملفات المؤقتة، ولقطات الاختبار المحلية (قد تحمل بيانات من صفحات حقيقية)، وأي سرّ أو مفتاح أو ملف تعريف متصفح.

## ما يُتتبَّع وما يُولَّد

- **يُتتبَّع:** الأصول المصدرية، والنصوص، وصادرات الصور النهائية (الأيقونات واللقطات وصور المتاجر وصورة README)، لأنها تُراجَع وتُربط من README وصفحات الموقع.
- **يُولَّد ولا يُتتبَّع:** `dist/` (بـ`npm run build`) و`packages/` (حزم `zip` يبنيها `node scripts/package.mjs`). وفي `.gitignore` استثناء صريح لـ`release/screenshots/` من قاعدة `screenshots/` العامة، لأن لقطات الإصدار تُتتبَّع خلافًا للقطات الاختبار المحلية.

## أنواع الصور وأين تجدها

| النوع | أين | ما هو |
| :--- | :--- | :--- |
| **لقطات حقيقية** | [`screenshots/`](screenshots/) (18 ملفًا) | التقطها المتصفح من الحزمة المبنية فوق صفحات GitHub تجريبية، بلا تعديل في المنتج. صيغة «بشريط عنوان» تضع شريط الشعار والتعليق فوق اللقطة نفسها |
| **صور هوية مصمَّمة** | [`artwork/readme/`](artwork/readme/) | رأس README (فاتح وداكن): الشعار وسطر التعريف ورسم مجرد. ليست لقطة من المنتج |
| **صور ترويج المتاجر** | [`artwork/store/`](artwork/store/) | صورتا Chrome وEdge: الشعار ورسم مجرد، لا لقطة ولا نص غير الشعار |
| **الأيقونات** | [`icons/`](icons/) | صادرات PNG من Figma؛ هي مصدر أيقونات الحزمة (`scripts/build.mjs`) |
| **أصول الشعار** | [`brand/`](brand/) | SVG من Illustrator: المعتمد `Mj2.svg` وحرف الأيقونة `mm.svg` |
| **صور صفحة الموقع `/Mjhr`** | خارج هذا المستودع: `public/Mjhr/` في مستودع الموقع `WebSiteSultan` | اقتطاعات من لقطات `--clean--` بلا تعديل غير القص (الجدول في [`screenshots/README.md`](screenshots/README.md#صور-صفحة-الموقع)) وأيقونة SVG من `mm.svg` وصورة مشاركة من `artwork/readme/hero-light.png` |

**الخصوصية (فُحصت في 2026-10-25):** لا قطعة وصفية في اللقطات وصور المتاجر؛ والأيقونات وصور README من Figma تحمل قطعة نصية واحدة `Software=Figma` (وقطع اللون والكثافة)؛ وملفات `brand/` تحمل تعليق مولّد Illustrator، ويزيد عليه `Mj2.svg` بيانات XMP (معرّفات مستند Adobe ورابط C2PA) دون مسار محلي أو اسم مستخدم. ولا اسم حقيقي ولا رمز ولا مفتاح في أي لقطة.

## متطلبات المتاجر الرسمية

قُرئت الصفحات الرسمية في 2026-10-25 وأُعيدت قراءتها في اليوم نفسه، وتُراجع مرة أخرى وقت التقديم لأنها قد تتغير.

| المادة | Chrome Web Store (ومنه Brave) | Microsoft Edge Add-ons | Firefox Add-ons (AMO) |
| :--- | :--- | :--- | :--- |
| أيقونة المتجر | 128×128 PNG داخل الحزمة؛ الرسم 96×96 وحوله 16 شفافة | شعار 1:1، المقترح 300×300 والأدنى 128×128 | من أيقونات المانيفست؛ يُوصى بـ32 و64 |
| اللقطات | 1–5، بمقاس 1280×800 (أو 640×400)، حتى الحواف وبزوايا قائمة | حتى 6، بمقاس 1280×800 أو 640×480 | بلا حد عملي، 1280×800 (نسبة 1.6:1)، ويُفضَّل بلا نص فوق الصورة |
| صورة ترويجية صغيرة | 440×280 (اختيارية، وتُقدَّم الإضافات التي لها) | 440×280 (اختيارية) | — |
| صورة ترويجية كبيرة | 1400×560 (اختيارية، شرط للظهور في الواجهة) | 1400×560 PNG (اختيارية) | — |
| الوصف القصير | حقل `description` في المانيفست، حتى 132 حرفًا | من `description` في المانيفست | الملخص حتى 250 حرفًا |
| الوصف الكامل | بلا حد معلن | من 250 إلى 10000 حرف | بلا حد عملي |
| أخرى | وصف الغرض الواحد، ومبررات الأذونات، وإفصاح البيانات، ورابط سياسة الخصوصية | الغرض الواحد، ومبررات الأذونات، والشيفرة البعيدة، وإفصاح البيانات، ورابط سياسة الخصوصية، وكلمات بحث (حتى 7، وكل منها حتى 30 حرفًا) | سياسة خصوصية لأن بيانات قد تخرج من الجهاز، وترخيص يُختار من قائمة AMO (المعتمد All Rights Reserved)، و**رفع الشيفرة المصدرية** لأن الحزمة مجمّعة بـVite |

المصادر: [Chrome: Supplying images](https://developer.chrome.com/docs/webstore/images) · [Chrome: Store listing](https://developer.chrome.com/docs/webstore/cws-dashboard-listing) · [Chrome: manifest description](https://developer.chrome.com/docs/extensions/reference/manifest/description) · [Edge: Publish an extension](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension) · [AMO: Create an appealing listing](https://extensionworkshop.com/documentation/develop/create-an-appealing-listing/) · [AMO: Submitting an add-on](https://extensionworkshop.com/documentation/publish/submitting-an-add-on/)

**ما يترتب على ذلك:** مجموعة لقطات واحدة بمقاس 1280×800 تكفي المتاجر الثلاثة، في صيغتين: بشريط عنوان قصير لـChrome وEdge، وبلا نص لـAMO مع التعليق في نص المتجر. وصورتا الترويج بمقاسين يشتركان بين Chrome وEdge، وبلا نص غير الشعار. واللقطات وصورتا الترويج PNG بـ24 بت بلا قناة شفافية، وهي الصيغة التي تقبلها المتاجر الثلاثة دون شرط إضافي؛ والأيقونات وحدها بقناة شفافية.
