## التثبيت — `#install`

- **تنبيه في أول القسم:** لم يُنشر مِجهَر في المتاجر بعد؛ تظهر روابطه هنا وفي صفحته عند النشر. **[بعد M] [قرار]**
- **Chrome وBrave:** من Chrome Web Store `⟨رابط⟩` اختر «إضافة إلى Chrome». يقبل Brave إضافات متجر Chrome.
- **Edge:** من Microsoft Edge Add-ons `⟨رابط⟩` اختر «الحصول».
- **Firefox:** من Firefox Add-ons `⟨رابط⟩` اختر «إضافة إلى Firefox». يتطلب Firefox 140 أو أحدث.
- **ما يطلبه عند التثبيت:** صلاحية موقع واحدة على github.com. وما سواها اختياري، يطلبه مِجهَر لاحقًا حين تفعّل ميزة تحتاجه.

## أول استعمال — `#first-use`

1. افتح أي صفحة في GitHub: مستودعًا أو طلب دمج أو مشكلة أو سجل فحص.
2. افتح لوحة مِجهَر بزرّه في شريط أدوات المتصفح، أو بالاختصار `Alt+G` (وفي macOS `Control+Shift+G`)، أو اختر مِجهَر من قائمة اللوحة الجانبية في متصفحك (الشريط الجانبي في Firefox).
3. في أول مرة يعرّفك الترحيب في خطوتين بما يعمل الآن وبالإضافات الاختيارية. تخطَّه متى شئت، وتعيده من الإعدادات ← «البداية والمساعدة».
- **مكان اللوحة:** من الإعدادات ← «مكان اللوحة» تختار بين اللوحة الجانبية للمتصفح ودرج يُفتح داخل صفحة GitHub.
- **الاختصارات:** `Alt+G` يفتح اللوحة أو الدرج، و`Alt+K` يبحث في قاموس المصطلحات؛ وفي macOS `Control+Shift+G` و`Control+Shift+K` لأن Option مع حرف يكتب فيه رمزًا. و`Alt+H` داخل صفحة GitHub يبدّل وضع الشرح، إلا في Firefox على Windows وLinux حيث يفتح قائمة Help فلا اختصار للوضع فيه، ويبقى زر «وضع الشرح» في اللوحة. وتغيّر اختصاري اللوحة والقاموس من صفحة اختصارات الإضافات في متصفحك:

  | المتصفح | الصفحة |
  | :--- | :--- |
  | Chrome | `chrome://extensions/shortcuts` |
  | Edge | `edge://extensions/shortcuts` |
  | Brave | `brave://extensions/shortcuts` |
  | Firefox | `about:addons` ← ترس الإعدادات ← «إدارة اختصارات الإضافات» |

  هذه عناوين داخلية في المتصفح تُكتب نصًّا قابلًا للنسخ لا روابط (لا تفتحها صفحة ويب)، وكل مسار داخل `<bdi dir="ltr">`.

## الرمز أم المفتاح؟ — `#token-vs-key`

لا يغني أحدهما عن الآخر: الرمز يتيح لمِجهَر قراءة بيانات من GitHub نيابةً عنك، والمفتاح يتيح تحليلًا نصيًّا عند المزوّد الذي تختاره. وكلاهما اختياري.

| | رمز GitHub للقراءة | مفتاح مزوّد التحليل |
| :--- | :--- | :--- |
| **ما هو** | رمز وصول بصلاحيات محددة تنشئه من حسابك في GitHub، واسمه فيه: Fine-grained personal access token | مفتاح API تنشئه من حسابك لدى المزوّد |
| **ما يضيفه** | حالة طلبات الدمج وفحوص Actions في مستودعاتك الخاصة التي تختارها، وحد طلبات أعلى (5000 بدل 60 في الساعة) | تحليل داخل الأقسام: شرح فشل الفحص، ومراجعة تغييرات طلب الدمج، وفهم المشكلة |
| **إلى أين يُرسل** | api.github.com وحده | مضيف المزوّد الذي تختاره وحده |
| **متى** | مع طلبات القراءة التي تبدؤها من مِجهَر | عند التحقق من المفتاح، ومع كل تحليل توافق عليه |
| **الصلاحية الاختيارية** | api.github.com | مضيف المزوّد، ومعها في Firefox موافقة «محتوى المواقع» |
| **أين يُحفظ** | ذاكرة الجلسة افتراضًا، أو القرص باختيارك (لا في Firefox) | مثله، ولكل مزوّد مفتاحه |
| **المزوّدون** | — | Anthropic وOpenAI وGoogle Gemini (مدمجة في الشيفرة؛ متاحة بأول إصدار منشور **[بعد M]**) |

## إعداد رمز GitHub — `#github-token`

1. في مِجهَر افتح الإعدادات ← الاتصالات ← «رمز GitHub للقراءة»، ثم «كيف تحصل على الرمز؟» لدليل مصوّر من سبع خطوات.
2. أنشئ الرمز في GitHub من [الصفحة المعبّأة](https://github.com/settings/personal-access-tokens/new?name=Mijhar+read-only&description=Mijhar+browser+extension%3A+read-only+access+to+pull+request+status+and+Actions+checks+in+the+repositories+you+select.&expires_in=90&metadata=read&contents=read&pull_requests=read&statuses=read&actions=read&issues=read): تملأ الاسم ومدة 90 يومًا وصلاحيات القراءة الست (Metadata وContents وPull requests وCommit statuses وActions وIssues، كلها Read-only). اختر المستودعات التي تريدها، ثم «Generate token». لا ينشئ الرابط شيئًا قبل نقرك.
3. انسخ الرمز والصقه في مِجهَر، واختر مكان حفظه، ثم «احفظ».
4. امنح صلاحية api.github.com حين يطلبها مِجهَر.
5. يتحقق مِجهَر بطلب واحد ويعرض حد الطلبات وموعد انتهاء الرمز.

**حدود الرمز:** فحوص التطبيقات غير Actions في المستودعات الخاصة لا تتيحها GitHub لهذا النوع من الرموز، فتظهر «غير متاحة». ونص سجل المهمة يُقرأ من صفحة المهمة نفسها لا عبر الرمز.

## إعداد مفتاح التحليل — `#provider-key`

**المزوّدون:** Anthropic وOpenAI وGoogle Gemini، في قائمة المزوّد بجانب كل منهم حالة مفتاحه. **[بعد M]**: مدمجة في الشيفرة محليًا ولا إصدار منشور بعد؛ لا تُنشر الصفحة بهذا السطر قبل إصدار يتضمنها.

1. في الإعدادات ← الاتصالات ← بطاقة «مزوّد التحليل»: **اختر المزوّد من القائمة**. لكل مزوّد مفتاحه وإعداداته، وتبديل المزوّد لا يمس مفتاح غيره.
2. **أنشئ مفتاح API من حسابك لدى المزوّد:**
   - Anthropic: مفتاح Claude API من Claude Console: شخصي أو لحساب خدمة أو لمساحة عمل، وكلها تبدأ بـ`sk-ant-`؛ لا مفتاح إدارة (Admin). ويفحص مِجهَر شكل المفتاح محليًا فقط (يبدأ بـ`sk-ant-` في سطر واحد بلا مسافات)، والحكم على صلاحه للمزوّد عند التحقق.
   - Anthropic ومساحة العمل: إن لم يكن مفتاحك الشخصي أو مفتاح حساب الخدمة مقيّدًا بمساحة عمل واحدة، يرد التحقق بأنه يلزمه معرّف مساحة عمل؛ فاكتب معرّفها (`wrkspc_…` من عمود ID في صفحة Workspaces في Claude Console) في حقل «معرّف مساحة العمل» في البطاقة ثم «تحقق من المفتاح». يُرسل مع كل طلب إلى Anthropic في ترويسة `anthropic-workspace-id`، ولا يخمّنه مِجهَر ولا يغيّر شيئًا في حسابك. وهذا الرد لا يعني أن المفتاح مرفوض.
   - OpenAI: مفتاح API عادي من منصة OpenAI، لا مفتاح إدارة (Admin).
   - Google Gemini: مفتاح Gemini API من Google AI Studio.
3. **الصقه واختر مكان حفظه، ثم «احفظ وتحقق».** يطلب المتصفح صلاحية مضيف هذا المزوّد وحده، وفي Firefox موافقة «محتوى المواقع» معها. ثم يرسل مِجهَر طلبًا واحدًا يقرأ النماذج المتاحة لمفتاحك، ولا يحمل شيئًا من صفحاتك. وإن كان حقل النموذج فارغًا وأعلن المزوّد توافق نماذجه مع التحليل (Anthropic) يقترح مِجهَر أولها، ولك تغييره.
4. **اكتب معرّف النموذج** في حقل «النموذج» كما يسمّيه المزوّد؛ والحقل هو الأساس. وزر **+** بجانبه (اسمه لقارئ الشاشة «اعرض نماذج ‹المزوّد› للاختيار») يفتح قائمة نماذج المزوّد المختار للمساعدة فقط: اختيار نموذج منها يملأ الحقل ثم تُغلق القائمة، وتُغلقها Esc والنقر خارجها. ولا يشترط مِجهَر أن يكون المعرّف في القائمة، فتستطيع كتابة نموذج جديد دون تحديث الإضافة ما دام يعمل بواجهة الطلب التي يستعملها مِجهَر لذلك المزوّد. وإن تعذّر جلب القائمة يبقى الحقل يعمل، ومعه «أعد المحاولة». وقبل حفظ المفتاح يعمل الحقل وزر + معطّل.
5. **اختبار النموذج (اختياري):** «اختبر النموذج» يرسل طلبًا واحدًا إلى المزوّد للنموذج المكتوب وحده، بنص ثابت «ping» بلا شيء من صفحاتك، ويعرض قبوله أو رفضه باختصار، أو «لم يُحسم» حين يتعذّر الحكم لشبكة أو مصادقة أو حد طلبات (وهذا ليس رفضًا للنموذج). النتيجة تخص النموذج الذي اختبرته بالمفتاح الذي اختبرته به. ليس شرطًا للحفظ ولا للتحليل، ويظهر حيث يدعمه المحوّل (OpenAI وGoogle Gemini؛ لا اختبار في محوّل Anthropic الحالي).
6. **للتحليل:** اختر «حلّل…» في القسم، وراجع بطاقة «إرسال للتحليل»: المحتوى وحجمه وما حُجب منه، والمزوّد والنموذج اللذين سيُرسل إليهما فعلًا. لا يُرسل شيء إلا باختيارك «إرسال للتحليل».

إضافة المفتاح لا تبدأ أي تحليل. وإن رفض المزوّد النموذج أو الطلب، يعرض مِجهَر سببه في القسم، ولا يعيد الطلب تلقائيًا ولا يحوّله إلى مزوّد آخر. وإن استبدلت المفتاح أو مسحته أثناء طلب جارٍ، فلا تُنسب نتيجته إلا إلى المفتاح الذي أُرسل به، ويقول مِجهَر ما حدث: أعد المحاولة بالمفتاح الحالي إن استبدلته، أو أضف مفتاحًا إن مسحته. وتعرض «لماذا المفتاح؟» داخل الإعدادات ما يُرسل ومتى، وسياسة كل مزوّد في البيانات كما أعلنها؛ والتفصيل لكل مزوّد في [سياسة الخصوصية](/Mjhr/privacy#providers).

## التغيير والحذف — `#change-delete`

- **الاستبدال:** الصق الرمز أو المفتاح الجديد واحفظه؛ يحل محل القديم.
- **نقل مكان الحفظ:** احفظه من جديد في المكان الآخر؛ يُمحى من الأول.
- **تغيير المزوّد:** اختر مزوّدًا آخر من القائمة. لكل مزوّد مفتاحه ونموذجه، ولا يمس التبديل مفتاح غيره، ويبقى التحليل عند المزوّد المختار وحده.
- **تغيير النموذج:** اكتب معرّفًا آخر في حقل «النموذج» أو اختره بمساعدة زر +؛ وبطاقة الموافقة تعرض النموذج الذي سيُرسل إليه فعلًا.
- **الحذف:** «امسح الرمز» أو «امسح المفتاح» يمحوه فورًا من ذاكرة الجلسة ومن القرص، ويتعطل ما يعتمد عليه وحده؛ وحذف مفتاح مزوّد لا يمس مفاتيح غيره. وما اشتُق منه (نتيجة التحقق وقائمة النماذج ونتيجة الاختبار) لا يُعرض بعدها ولا يُستعمل، ويُحذف عند قراءة الحالة التالية.
- **أكثر من نافذة:** إن غيّرت الرمز أو المفتاح وصفحة الإعدادات مفتوحة في نافذة أخرى، فبطاقة «مزوّد التحليل» وبطاقتا رمز GitHub وقسم «الاتصالات» هناك تتحدث حين تعود إليها، دون إعادة تحميل.
- **سحب الصلاحيات:** «اسحب الصلاحية» لـapi.github.com، و«اسحب صلاحية ‹مضيف المزوّد›» لمزوّد واحد، وفي Firefox «اسحب موافقة محتوى المواقع (لكل المزوّدين)». أو من صفحة إضافات المتصفح.
- **الإبطال من المصدر:** المسح من مِجهَر لا يُبطل الرمز في GitHub ولا المفتاح عند المزوّد. أبطل الرمز من [Personal access tokens](https://github.com/settings/personal-access-tokens)، والمفتاح من حسابك لدى المزوّد.
- **إن قال مِجهَر إن الرمز انتهى أو رُفض:** امسحه واحفظ بدلًا منه. وإن قال إنه ينقصه صلاحية: أضفها من GitHub ثم اختر «تحقق من الرمز».

## رمز الكتابة في «تجهيز تعديل» — `#write-token`

- **ما يفعله:** يكتب مِجهَر ملفًا نصيًا واحدًا في فرع جديد ويفتح طلب دمج (مسودةً في المستودعات العامة)، بعد أن تعاين الفرق كاملًا وتوافق على النطاق وتنقر «نفّذ». ولا يدمج ولا يحذف ولا يغلق شيئًا.
- **الرمز:** رمز وصول بصلاحيات محددة آخر غير رمز القراءة، بصلاحيتي Contents وPull requests «Read and write» للمستودع الذي تعدّله وحده، مع صلاحية api.github.com الاختيارية. ويرفضه مِجهَر إن كان هو رمز القراءة نفسه.
- **حفظه:** في ذاكرة الجلسة وحدها، ولا يُستعمل في أي قراءة أو تحليل. امسحه بعد الانتهاء من «امسح رمز الكتابة».

## الإبلاغ عن مشكلة — `#report`

- **من داخل مِجهَر:** الإعدادات ← «حول مِجهَر» ← «الإبلاغ عن مشكلة» (ومن اللوحة: الإعدادات ← «البداية والمساعدة»). اختر نوع البلاغ واكتب ما حدث، فترى قبل الإرسال كل ما سيُرسل: نصك، وإصدار مِجهَر والمتصفح والنظام، ومكان اللوحة، والوحدات الموقوفة. ثم تضغط «أرسل البلاغ» بنفسك، فيطلب المتصفح أول مرة إذنك بالاتصال بخادم البلاغات وحده، ويصل البلاغ إلى قناة بلاغات خاصة لا تُنشر للعموم، ويظهر لك رقمه. ولا يُرفق رابط الصفحة ولا محتواها ولا اسم المستودع ولا رمز ولا مفتاح؛ وإن كان في نصك ما يشبه رمزًا أو مفتاحًا بصيغة معروفة نبّهك مِجهَر ولم يرسله حتى تحذفه. والتفصيل في [سياسة الخصوصية](/Mjhr/privacy#report).
- **أو بالبريد:** راسلني على [isultanby@gmail.com](mailto:isultanby@gmail.com)، أو انسخ البلاغ من الإضافة بزر «انسخ البلاغ بدل إرساله» وأرسله بطريقتك.
- **اكتب في البلاغ:** ما فعلته، وما توقعته، وما حدث، ونوع الصفحة (طلب دمج، مشكلة، ملف، سجل فحص…). وفي البريد اذكر أيضًا المتصفح وإصداره وإصدار مِجهَر كما تعرضه صفحة إضافات المتصفح.
- **لا ترفق:** رمزًا أو مفتاحًا أو محتوى من مستودع خاص. وإن أرفقت صورة بالبريد فاحجب منها ما لا تريد مشاركته.

## أسئلة قصيرة — `#faq`

- **هل أحتاج مفتاحًا أو رمزًا لاستعمال مِجهَر؟** لا. الميزات الأساسية ونسخ البرومبت تعمل بلا أي منهما.
- **لماذا لا تظهر الترجمة في Edge أو Firefox؟** يترجم مِجهَر بمحرك المتصفح نفسه، وهو متاح اليوم في Chrome وBrave. وفي غيرهما يقول مِجهَر إن الترجمة غير متاحة بدل أن يرسل النص إلى خدمة خارجية.
- **هل أحتاج تحديث الإضافة لأستعمل نموذجًا جديدًا؟** لا، ما دام النموذج يعمل بواجهة الطلب التي يستعملها مِجهَر لذلك المزوّد: اكتب معرّفه في حقل «النموذج».
- **إلى أين يذهب ما أوافق على إرساله للتحليل؟** إلى المزوّد الذي اخترته وحده، عبر مضيفه المذكور في بطاقة الموافقة. ولكل مزوّد سياسته فيما يحفظه ومدته واستعماله، وتجدها في [سياسة الخصوصية](/Mjhr/privacy#third-parties).
