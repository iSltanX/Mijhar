# MJ11 — تفسير الموانع ومحلل السجل وطبقة API العامة

> «ماذا ولماذا» في الخطة: [`T-5.2`](../../phases/phase-05-module-d.md#T-5.2) · [`T-5.3`](../../phases/phase-05-module-d.md#T-5.3)، والقسم 6 من [`EXECUTION_PLAN.md`](../../EXECUTION_PLAN.md). و«متى وكيف» في [`Docs/MJ/README.md`](../README.md).

## الهدف

الطبقة الثانية للوحدة (د): تفسير موانع الدمج بالأدلة وبيان المصدر والتقادم وطبقة REST API العامة عبر الصلاحية الاختيارية، ومحلل وشرح سجل الفحص بثلاث طبقات.

## لماذا الآن

تعتمد على بطاقة حالة PR المدمجة في D وعلى `T-0.3`؛ ملفاتها في `modules/d` و`core/api` منفصلة.

## النطاق

**الملفات التي تملكها المرحلة**

- `src/modules/d/blockers/` و`src/modules/d/log-parser/` و`src/core/api/` (طبقة الطلبات العامة والتخزين المؤقت وترويسات `x-ratelimit-*`)
- `tests/modules/d/` و`tests/core/api/` و`fixtures/logs/`

**الملفات المشتركة مع مراحل الموجة** (تُضم بترتيب الدمج لا باختيار نسخة)

- `src/core/index.ts`: تصدير طبقة API.

**خارج النطاق**

- رمز الوصول (`MJ15`): هنا طلبات عامة بلا مصادقة فقط.

## المهام

1. `T-5.2` — تفسير موانع الدمج بالأدلة وبيان المصدر والتقادم وطبقة API العامة (`F-D3`, `F-D4`) ([التفاصيل ومعايير القبول](../../phases/phase-05-module-d.md#T-5.2)).
2. `T-5.3` — محلل وشرح سجل الفحص بثلاث طبقات (`F-D5`) ([التفاصيل ومعايير القبول](../../phases/phase-05-module-d.md#T-5.3)).

## معايير القبول

- `AC-D3`: كل سبب لمنع الدمج معروض مقرون بدليل مرصود (نص في صندوق الدمج أو حقل في API)؛ لا يُعرض سبب بلا دليل؛ التنبيه المنهجي الدائم بأن نجاح الفحوص لا يعني جاهزية المشروع ظاهر؛ ولا تظهر عبارة تجزم بأن الطلب «جاهز للدمج».
- `AC-D4`: تعرض الشارة المصدر (DOM أو DOM + API) ووقت آخر قراءة؛ وتظهر التنبيهات في ثلاث حالات: قائمة فحوص مطوية جزئيًا، تجاوز عتبة التقادم القابلة للضبط، ورود تحديث حي؛ وبعد التحديث يتجدد الوقت.
- `AC-D5`: على السجل المرجعي: الطبقة الأولى تعرض الرسالة الحرفية وموضعها (الخطوة وكود الخروج والأسطر المحيطة)؛ الطبقة الثانية لا تُملأ إلا عند تطابق نمط حتمي من قائمة الأنماط المعرّفة وإلا ظهرت عبارة «لا يوجد سبب جذري مثبت من نص السجل وحده»؛ الطبقة الثالثة موسومة «احتمال يحتاج تحققًا»؛ لا تختلط الطبقات؛ والسجل المقتطع أو غير المتاح يُعلَن.

## الفحوص

- اختبارات الخطة لمهام المرحلة: `TEST-PR-03`، `TEST-PR-04`، `TEST-LOG-01`.
- `npx vitest run tests/modules/d tests/core/api` أخضر (`TEST-PR-03` و`TEST-PR-04` و`TEST-LOG-01`).
- تدقيق شبكة: لا طلب إلى `api.github.com` دون الصلاحية الاختيارية الممنوحة بنقر صريح؛ مسجَّل في `evidence/T-5.2/`.
- المتصفحات المتاحة Chrome وEdge وBrave؛ وكل بند يخص Firefox يُسجَّل «لم يُجرَ» ما دام غير مثبت (`EV-06`)، ولا يُغلق به معيار.
- الفحوص بحسب الأثر: ما تمسّه المرحلة فقط، ولا يُعاد طقم كامل بعد كل تعديل؛ والفحوص التي تشترك في متصفح أو منفذ تُجرى متسلسلة.
