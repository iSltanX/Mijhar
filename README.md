# مِجهَر

**إضافة متصفح تجعل GitHub أوضح لمن يقرأ ويكتب بالعربية.** يصحّح اتجاه النص العربي في صفحات GitHub، ويشرح الأزرار والمصطلحات في مكانها، ويقرأ لك حالة طلب الدمج وأين فشل الفحص ولماذا. يعمل فور التثبيت، بلا حساب ولا مفتاح.

> **الحالة:** مِجهَر لم يُنشر في متاجر الإضافات بعد. تُضاف روابط التثبيت هنا عند نشره، وحتى ذلك الحين يمكنك [بناؤه وتجربته من المصدر](#التثبيت).

## لمن مِجهَر؟

- لمن يكتب على GitHub بالعربية ويتعب من الفقرات المقلوبة والكود المبعثر داخلها.
- لمن يتعلم GitHub ويريد أن يفهم الزر قبل أن يضغطه.
- لمن يراجع طلبات الدمج ويريد أن يعرف بسرعة ما يمنع الدمج، ولماذا فشل الفحص، دون أن يقرأ السجل كله.
- لمن يسأل نموذج ذكاء اصطناعي عن مشكلة ويريد أن يعطيه سياقًا صحيحًا من الصفحة.

## ما يعمل فور التثبيت

| | الميزة | ما تفعله |
| :---: | --- | --- |
| ١ | **العربية في اتجاهها الصحيح** | يقلب الفقرات العربية من اليسار إلى اليمين، ويعزل الكود والمسارات داخلها، ويضيف إلى محرر التعليق زرًّا يبدّل اتجاه الحقل. ومعه وضع قراءة هادئ، وترجمة المحدَّد بمحرك متصفحك نفسه حيث يتيحه (Chrome وBrave). |
| ٢ | **الواجهة مشروحة في مكانها** | اطلب شرح زر أو مصطلح فيظهر معناه بالعربية بجانبه، ومتى تستعمله، وهل يمكن التراجع عنه. ومعه قاموس للمصطلحات وجولات قصيرة على عناصر الصفحة الحقيقية. |
| ٣ | **لماذا لا يُدمج الطلب؟** | بطاقة تلخّص ما يمنع الدمج والفحوص والمراجعات المطلوبة. وإن فشل فحص في Actions قرأ سجله وأشار إلى السطر الذي يثبت السبب، ويقول «لا سبب مثبت» حين لا يجد دليلًا بدل أن يخمّن. |
| ٤ | **سياق المهمة جاهزًا لأي نموذج** | يجمع الوصف والفحوص ومقتطف الخطأ والتعليقات ذات الصلة في حزمة تراجعها ثم تنسخها برومبتًا، وينبّهك إلى صيغ الأسرار المعروفة قبل النسخ. |
| ٥ | **ملاحظاتك في متصفحك** | ملاحظات خاصة على سطر أو صفحة، و«أكمل لاحقًا»، والتصدير والاستيراد. |

وأيضًا: مرشد أول مساهمة، ومعالج README بالعربية، وبنك عبارات المراجعة، وترجمة مسودتك قبل نشرها.

## الإضافات الاختيارية: رمز GitHub ومفتاح التحليل

لا يتوقف عليهما شيء مما سبق، ولا يغني أحدهما عن الآخر. أضف ما تحتاجه منهما فقط، واحذفه متى شئت.

| | رمز GitHub للقراءة | مفتاح مزوّد التحليل |
| --- | --- | --- |
| **ما هو** | رمز وصول بصلاحيات محددة تنشئه من حسابك في GitHub، واسمه هناك Fine-grained personal access token | مفتاح API تنشئه من حسابك لدى المزوّد: Anthropic أو OpenAI أو Google Gemini |
| **ما يضيفه** | حالة طلبات الدمج وفحوص Actions في مستودعاتك الخاصة التي تختارها، وحد طلبات أعلى من GitHub | تحليل نصي داخل الأقسام: شرح فشل الفحص، ومراجعة تغييرات طلب الدمج، وفهم المشكلة |
| **إلى أين يُرسل** | `api.github.com` وحده | مضيف المزوّد الذي تختاره وحده |
| **متى** | مع طلبات القراءة التي تبدؤها من مِجهَر | عند التحقق من المفتاح، ومع كل تحليل توافق عليه |

**قبل كل تحليل** تعرض بطاقة «إرسال للتحليل» المحتوى الذي سيُرسل وحجمه وما حُجب منه، والمزوّد والنموذج اللذين سيُرسل إليهما فعلًا. لا يُرسل شيء إلا حين تختار «إرسال للتحليل»، ولا يُرفق رمز GitHub بأي طلب إلى المزوّد. والنموذج تكتب معرّفه بنفسك، ويساعدك زر **+** بقائمة نماذج المزوّد.

**«نسخ البرومبت» لا يحتاج مفتاحًا:** يجهّز السياق نفسه لتلصقه في أي نموذج تستعمله.

أما ما يحفظه كل مزوّد مما يصله ومدته، فتحكمه سياسته هو لا مِجهَر، والتفصيل في [سياسة الخصوصية](PRIVACY.md#third-parties).

## الخصوصية باختصار

- لا حساب، ولا قياس استخدام ولا إعلانات. ولا تتصل الإضافة بخادم للمطوّر إلا حين ترسل أنت بلاغًا عن مشكلة بعد أن ترى كل ما فيه.
- إعداداتك وملاحظاتك في تخزين الإضافة في هذا المتصفح، ولا تُزامَن مع أي خدمة.
- يقرأ مِجهَر من `github.com` نفسه ما تحتاجه صفحة طلب الدمج. ولا يتصل بـ`api.github.com` ولا بمزوّد التحليل إلا بطلبك.
- الرمز والمفاتيح في ذاكرة الجلسة افتراضًا، وتُمحى بإغلاق المتصفح. والحفظ على القرص اختيار تعلنه أنت، وهو غير مشفَّر.
- المسح من مِجهَر لا يُبطل الرمز في GitHub ولا المفتاح عند المزوّد؛ أبطلهما من حسابك هناك إن لم تعد تحتاجهما.

التفصيل جملةً جملة في [سياسة الخصوصية](PRIVACY.md).

## التثبيت

### من المتاجر

لم يُنشر بعد في Chrome Web Store ولا Microsoft Edge Add-ons ولا Firefox Add-ons. تُضاف الروابط هنا عند النشر.

### من المصدر

تحتاج Node.js 22 أو أحدث. من مجلد المستودع:

</div>

```bash
npm ci
npm run build
```

<div dir="rtl">

فينتج البناء مجلدين: `dist/chromium` لـChrome وEdge وBrave، و`dist/firefox` لـFirefox.

- **في Chrome وEdge وBrave:** افتح صفحة الإضافات في متصفحك (مثل `chrome://extensions`)، وفعّل وضع المطوّر (Developer mode)، ثم اختر تحميل الإضافة غير المضغوطة (Load unpacked) وحدّد مجلد `dist/chromium`.
- **في Firefox:** افتح `about:debugging#/runtime/this-firefox`، واختر تحميل إضافة مؤقتة (Load Temporary Add-on)، وحدّد الملف `dist/firefox/manifest.json`. تبقى الإضافة المؤقتة حتى تغلق Firefox.

يعمل على Chrome وEdge وBrave بالإصدار 114 أو أحدث، وعلى Firefox بالإصدار 140 أو أحدث.

## أول استعمال

1. افتح أي صفحة في GitHub: مستودعًا أو طلب دمج أو مشكلة أو سجل فحص.
2. افتح لوحة مِجهَر بزرّه في شريط أدوات المتصفح، أو بالاختصار <kbd>Alt</kbd>+<kbd>G</kbd> (وفي macOS <kbd>Control</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd>).
3. في أول مرة يعرّفك الترحيب في خطوتين بما يعمل الآن وبالإضافات الاختيارية. تعيده متى شئت من الإعدادات.

والقاموس بالاختصار <kbd>Alt</kbd>+<kbd>K</kbd> (وفي macOS <kbd>Control</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>). وتغيّر الاختصارين من صفحة اختصارات الإضافات في متصفحك.
