## ما نُفّذ

- ميزة `isolation` في `src/modules/a/isolation/` تُركَّب بعد ميزة الاتجاه. تعمل في الكتل rtl داخل حاويات Markdown: ما قلبته ميزة الاتجاه، وما يعرضه GitHub rtl بـ`dir="auto"`.
  - العناصر الموجودة أصلًا (`code` و`kbd` و`samp` و`pre` و`a.user-mention` و`a.team-mention` و`a.issue-link` و`a.commit-link` و`span.reference`) تعزلها قاعدة CSS وحدها: `direction: ltr; unicode-bidi: isolate`. ولا يُمس منها شيء في DOM.
  - الروابط التي نصها لاتيني خالص تُعلَّم بسمة `data-mijhar-isolate` تعزلها القاعدة نفسها.
  - المسارات والإصدارات والمراجع (`#452` و`owner/repo#12`) والإشارات وأسماء الملفات المكتوبة نصًا عاديًا تُغلَّف بـ`span.mijhar-bidi-isolate`. تُستبدل العقدة النصية بعنصر تجميع عبر `MutationRecorder.replace`، فيعيد الإيقاف العقدة الأصلية نفسها.
- **لا محرف توجيه خفي ولا سمة `dir`** على ما يُحقن. سمة `dir` على الـspan تجعل المتصفح يتخطاه عند حساب `dir="auto"` للفقرة، فيتغير اتجاهها، والعزل يأتي من CSS وحده.
- **التغليف داخل حاويات Markdown وحدها.** نصها HTML يضعه GitHub كتلة واحدة. أما العناوين وصفوف الالتزامات في صفحات React فنصها تملكه React، فلا تُقسم عقدها، ويعزل CSS عناصرها القائمة فقط.
