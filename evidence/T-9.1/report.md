# تقرير `T-9.1`: كاشف README العربي وبيان نطاق الفحص (`AC-H1`، `TEST-COMM-01`)

> التاريخ 2026-10-23. الفرع `mj/9-notes-community-first-layer`.

## ما نُفِّذ (`src/modules/h/readme-detector/`)

- `detect.ts`: دالة نقية على صفوف شجرة الجذر وروابط README الأساسي. الأنماط من قياس `evidence/T-0.4` (`^readme[._-](ar|ara|arabic)([._-][a-z]{2})?\.(md|markdown|rst|txt|adoc)$` للاسم، وللرابط الاسم نفسه أو `[/_-]ar(-xx)?.md` أو `ar/README.md`)، وروابط المستودع نفسه وحده (blob وtree وraw). ثلاث حالات: `found` و`not-found-in-scope` و`unreadable`.
- `extract.ts`: قراءة DOM بمحددات في `SelectorsRegistry` مقيسة على لقطة حية محفوظة (`fixtures/spikes/gh-repo-arabic-stop-words.html`: `table[aria-labelledby="folders-and-files"] tr.react-directory-row a.Link--primary`)، وإعلان الاقتطاع من بيانات الصفحة المضمّنة (`items < totalCount`) أو عبارة «we had to truncate… N entries were omitted» (T-0.4: 1000 من 5108).
- `ReadmeBanner.tsx`: الشريط قبل README. عند العثور: «يتوفر ملف تعريف باللغة العربية…» ورابطه. وعند عدم العثور: بيان النطاق **بنص الخطة** (شجرة الجذر الظاهرة والروابط المباشرة داخل README الأساسي، وقد تكون القائمة ناقصة أو مقطوعة أو التوثيق في مجلد فرعي مثل docs/ أو i18n/) مع ما فُحص فعلًا والمجلدات غير المفتوحة والاقتطاع بأرقامه، وزر «فحص مجلد docs/ عند الطلب». وحالة `unreadable`: «لم يُفحص شيء».
- `docs-scan.ts`: فحص `docs/` بطلبات `GET /repos/<o>/<r>/contents/docs` (ثم مجلد لغة `ar` على الأكثر)، بحد ثلاثة طلبات، وأول ما في معالج النقر طلب الصلاحية (بلا `await` قبله)، وكل فشل (رفض أو حد طلبات أو 404 أو خطأ أو ردّ غير متوقع) يعلن «لم يكتمل»؛ وقراءة `docs/` كاملة بلا ملف عربي لا تُعلَن غيابًا للتوثيق العربي.
- `../api-access.ts`: كل طلب عبر `fetchApiGithub` (البوابة الوحيدة، `T-1.4`)؛ وواجهة الصلاحيات غير متاحة في سكربت المحتوى والدرج فيه، فيُعلن هناك أن الفحص يُجرى من اللوحة الأصلية ولا يُرسل شيء.
- `ReadmePanelView.tsx`: «README العربي» في لوحة المجتمع: فحص `docs/` للمستودع المفتوح (حيث تتوفر الصلاحية).
- `../module.tsx` (الوحدة `h`، صفحة `repo` بثقة `high`): إدراج الشريط بعد استقرار الصفحة (مراقبة تعديلات مؤجلة، ومهلة 4 ثوانٍ قبل «تعذّرت القراءة»).
