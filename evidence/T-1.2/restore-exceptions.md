# استثناءات الاستعادة — ما لا يغطيه سجل التعديلات (AC-1.2 بند 4)

المصدر الوحيد في الشيفرة: [`src/core/lifecycle/restore-exceptions.ts`](../../src/core/lifecycle/restore-exceptions.ts). هذا الملف عرضٌ له، ويفحص `tests/core/lifecycle/restore.test.ts` أن كل معرّف في الشيفرة مذكور هنا.

المبدأ (`EXECUTION_PLAN.md` ‏1.1 البند 2): الإضافة تستعيد ما سجّلته ولم يغيّره غيرها بعد ذلك. ما غيّره GitHub أو المستخدم أو طرف ثالث بعد كتابتها **لا يُلمس**، ولا يُدّعى له استعادة. السجل يغطي فقط ما يمرّ بـ`ctx.mutations`.

العمود «يُرصد» يعني: يظهر وقت التشغيل في `RestoreReport.skipped` برقمه. وغير المرصود حدٌّ تصميمي لا يمكن رصده من داخل السجل.

| المعرّف | ما لا يُستعاد | ما يحدث فعلًا | يُرصد |
| :--- | :--- | :--- | :---: |
| `direct-dom-mutation` | تعديل DOM بغير واجهة السجل (`innerHTML` و`textContent` و`el.hidden` و`appendChild`…) | لا يُستعاد؛ على الوحدة استعمال `ctx.mutations` أو `ctx.mutations.custom` | لا |
| `text-nodes` | نصوص العقد النصية: الحارس المبني على سجل الكتابات لا على مقارنة النص عملُ `T-2.7` | لا يُدّعى استعادة نص لم يمرّ بمحرك `T-2.7`، وهو يسجّل استعادته عبر `custom` | لا |
| `external-attribute-change` | سمة غيّرها طرف آخر بعد كتابة الإضافة (أو حذفها، أو أعاد كتابة سمة أزالتها الإضافة) | تُترك بقيمتها الحالية. حدّ: كتابة طرف آخر بقيمة مطابقة لما كتبته الإضافة تُعامَل كملكها | نعم |
| `external-style-change` | خاصية `style` مضمّنة غيّرها طرف آخر | تُترك كما هي، وبنفس حدّ المساواة | نعم |
| `replaced-node-lost` | عقدة استبدلتها الإضافة ثم فصلها GitHub | يُعتمد ما صنعه GitHub ولا يُدرَج الأصل | نعم |
| `replaced-original-reattached` | عقدة أصلية أعادها GitHub بنفسه | لا يُكتب فوقها؛ تُزال البديلة إن وُجدت | نعم |
| `custom-undo-failed` | استعادة مخصصة (`custom`) رمت استثناءً | يُسجَّل الخطأ وتستمر بقية الاستعادة | نعم |
| `undo-threw` | عملية DOM داخلية رمت وقت الاستعادة (مثل `HierarchyRequestError`) | يُسجَّل وتستمر بقية الاستعادة | نعم |
| `form-and-focus-state` | قيم الحقول والتركيز والتحديد والتمرير | لا تُستعاد | لا |
| `page-owned-state` | حالة الصفحة غير المرئية في DOM: مستمعات الصفحة وحالة React وذاكرة Turbo المؤقتة والتاريخ و`document.title` و`location` | خارج نطاق الإضافة؛ لا تُعدَّل ولا تُستعاد | لا |
| `adopted-stylesheets` | `adoptedStyleSheets` للمستند أو لجذور الظل | تُسجَّل عبر `custom` أو لا تُستعمل خارج مضيف الواجهات (`T-1.4`) | لا |
| `third-party-changes` | تعديلات إضافات أخرى أو ترجمة المتصفح لـDOM نفسه | تُعامَل كتغيير خارجي ولا تُلمس | لا |

## ما لا يُعدّ استثناءً

- **عنصر محقون أزاله GitHub أو Turbo قبل الإيقاف:** أثره زال بغير الإضافة والنتيجة النهائية متطابقة؛ يُعدّ `alreadyGone` في التقرير لا استثناءً.
- **كتابة بعد إغلاق الوحدة** (استمرار غير متزامن تأخر عن الإيقاف): تُرفض ولا تمسّ DOM، وتُحصى في `rejectedAfterClose`.
