## قاعدة القلب: مراجعة العتبة بنتائج `T-0.1`

الخطة اقترحت عتبة أولية «30% أو ثلاث كلمات عربية متصلة، وتُراجع بنتائج `T-0.1`». ووجد تقرير `T-0.1` أنها تقلب كتلًا ثنائية اللغة تبدأ بجملة إنجليزية كاملة (42 إلى 53%)، واقترح رفعها نحو 60% أو اشتراط ألا تبدأ الكتلة بجملة لاتينية.

القاعدة المعتمدة (`decide.ts`)، وكلها حيث يعرض GitHub الكتلة `ltr` فقط:

1. كتلة نسبة حروفها العربية ≥ 60% تُقلب.
2. كتلة مختلطة (30% إلى أقل من 60%، أو فيها ثلاث كلمات عربية متتابعة) تُقلب بحسب سياقها:
   - داخل حاوية محتوى (README أو تعليق): إن كانت نسبة الحروف العربية في الحاوية كلها ≥ 50%.
   - خارج الحاويات (عنوان، رسالة التزام، وصف مستودع): إن لم تبدأ بجملة لاتينية (أقل من ثلاث كلمات لاتينية قبل أول كلمة عربية).
3. لا يُكتب فوق `dir="ltr"` صريحة: GitHub لا يضعها في صفحاته (صفر في العينات الثماني)، فهي قصد المؤلف.

القياس على عينات `T-0.1` الثماني نفسها، 583 كتلة فيها حروف ([`threshold.json`](threshold.json)):

| القاعدة | كتل عربية | يُكتب عليها (يعرضها GitHub ltr) | يُكتب على كتلة بلا حرف عربي |
| :--- | ---: | ---: | ---: |
| الخطة الأولية: 30% أو ثلاث كلمات | 301 | 163 | 0 |
| اقتراح `T-0.1` الأول: 60% | 288 | 152 | 0 |
| اقتراح `T-0.1` الثاني: 60%، أو مختلطة لا تبدأ بجملة لاتينية | 296 | 158 | 0 |
| **المعتمدة** | 296 | 158 | 0 |

الفرق بين القاعدتين الأخيرتين في الكتل المختلطة وحدها (14 كتلة، كلها في `threshold.json`):

- الكتل الخمس التي تبدأ بجملة إنجليزية في سياق إنجليزي أو مستقلة **تبقى** `ltr`. هي `Deep learning for AR text Vocalization - …` ×2 و`Largest list of Arabic stop words on Github. …` ×2 (وصفا مستودعين)، و`Shakkala Project مشروع شكّالة` (عنوان README إنجليزي، نسبة حاويته 7%). والخطة الأولية كانت تقلبها كلها.
- العناصر المختلطة في قوائم عربية (`B طابور, Queue` و`A Strongly Connected Components - خوارزمية Kosaraju`، ونسبة الحاوية 85%) **تُقلب** مع جيرانها.
- رسالتا الالتزام `chore(security): ترقية dompurify …` (41%) و`… استثناء تنبيهي …` (57%) **تُقلبان**؛ كلتاهما تبدأ بكلمة لاتينية واحدة.
- الفرق مع اقتراح `T-0.1` الثاني في كتلتين تتبادلان الحكم، فتساوى العدد (158):
  - `Shakkala Project مشروع شكّالة`: الاقتراح يقلبها لأن في أولها كلمتين لاتينيتين فقط، والمعتمدة تُبقيها لأن حاويتها إنجليزية (7%).
  - `Test ETOSCore (iOS Simulator): ** TEST FAILED **. أول خطأ حقيقي …` (41%): الاقتراح يُبقيها لأن في أولها أربع كلمات لاتينية، والمعتمدة تقلبها لأنها في تعليق عربي (65%).

- الجهاز Apple M4، و`playwright-core` لعائلة Chromium، وMarionette لـFirefox.
- ملف تعريف مؤقت جديد بلا إضافات وبلا واجهة.

- **صفحات github.com الحية:** القياس على عينات `T-0.1` المحفوظة من صفحات حقيقية، وعلى العينة المكتوبة. لم تُفتح صفحة حية في هذه المرحلة.
