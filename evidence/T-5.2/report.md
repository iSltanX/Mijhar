## ما بُني

1. **طبقة API العامة `src/core/api/`** (تصدير من `src/core/index.ts`): `PublicApiClient` في الخلفية وصفحات الإضافة، وكل طلب يمر بـ`fetchApiGithub` (البوابة الوحيدة، `T-1.4`) فلا يخرج دون الصلاحية الاختيارية. GET وحده، لمسارات `/repos/…` و`/rate_limit` وحدها، بلا `Authorization` ولا ملفات تعريف. ترويسات `x-ratelimit-*` تُقرأ من كل استجابة، وعند `remaining = 0` لا يُرسل شيء حتى `reset`. طلبات شرطية بـ`ETag` تقلل النقل ولا يُدَّعى أنها توفّر الحد (`VER-12`، ومقيس في T-0.3). تصفّح الصفحات بحد أقصى معلن، والقائمة الجزئية تُعلَن. الفشل نتيجة مصنَّفة: `permission` و`rate-limit` و`not-found` و`forbidden` و`http` و`network` و`invalid-path`. ولسكربت المحتوى منفذ رسائل (`runtimePort`) إلى الخلفية التي تتحقق من الصلاحية (`src/background/main.ts`).
2. **مفسّر الموانع `src/modules/d/blockers/explain.ts`**: كل مانع يُبنى بـ`blocker()` التي ترفض مانعًا بلا دليل؛ والدليل نص منقول من صندوق الدمج أو الترويسة أو صف فحص، أو حقل API بقيمته ومساره. «يمنع» حين يقول الدليل نفسه إن الدمج ممنوع أو مشروط (تعارض يجب حله، مراجعة مطلوبة، فحص إلزامي لم ينجح أو لم يكتمل، مسودة، `mergeable_state` = `dirty` أو `blocked` أو `draft`)، و«قد يمنع» حين لا يحسم (التأخر، طلب التغييرات، فحوص فاشلة لا يُعرف أهي إلزامية، `behind`). والفاشل غير الإلزامي بحسب صندوق الدمج أو حماية الفرع ملاحظة لا مانع. والمدموج والمغلق لا يُفسَّر منعهما. والتنبيه المنهجي `METHOD_NOTICE` ظاهر دائمًا.
3. **دمج API في البطاقة `merge.ts`** بقواعد T-0.3: الهوية بمعرّف check run وسياق commit status، والأولوية لـAPI مع نقل شارة Required من DOM، والتعارض من صندوق الدمج وإلا `dirty` وإلا `mergeable = true`، و«لا فحوص» بـ`check-runs = 0` و`status = 0` معًا.
4. **الشارة والتنبيهات `freshness.ts`**: المصدر «DOM» أو «DOM + API» ووقت كل قراءة؛ وتنبيه القائمة المطوية (صفوف أقل مما يعلنه الرمز المجمَّع لالتزام الرأس، أو check-runs أكثر من حد الصفحات)، والتقادم بعتبة `PP-01` (5 دقائق افتراضًا، قابلة للضبط في الإعدادات بمفتاح `d.pr-status.staleMinutes`)، والتحديث الحي (قيمة مقروءة تغيّرت بعد تعديل أجرته الصفحة، لا ظهور قيمة كانت غير متاحة) فتُعاد القراءة ويتجدد وقتها، وتُعلَن بيانات API الأقدم منه. «أعد القراءة» يجدد الوقت ويجلب جزء `status-details` متجاوزًا الذاكرة.
5. **لوحة API في البطاقة**: لا طلب إلا بنقر «أكمل من GitHub API العامة» بعد منح الصلاحية من الإعدادات (لا تُطلب الصلاحية من الصفحة)؛ أربعة طلبات: الطلب، وcheck-runs لالتزام الرأس، وcommit status، وحماية فرع الهدف.

## تدقيق الشبكة (`لا طلب إلى api.github.com دون الصلاحية الاختيارية الممنوحة بنقر صريح`)

على الحزمة المشحونة في المتصفحات الأربعة، والصفحات وapi.github.com تُخدم محليًا بردود مسجلة (لا شبكة خارجية):

| المرحلة | Chrome | Edge | Brave | Firefox |
| :--- | :---: | :---: | :---: | :---: |
| قبل المنح: PR معقدة وحقيقية وصفحتا مهمة (لا زر API، «افتح الإعدادات» وحده) | 0 طلب | 0 | 0 | 0 |
| بعد المنح وقبل النقر على «أكمل من GitHub API العامة» | 0 | 0 | 0 | 0 |
| بعد النقر | 4 بالضبط | 4 | 4 | 4 |
| السياق المرسِل | service worker | service worker | service worker | الخلفية (بلا `Authorization` ولا ملفات تعريف، مقيس في الخادم) |

**طريقة المنح:** في Firefox بنقر «امنح» في صفحة الإعدادات الحقيقية (`extensions.webextOptionalPermissionPrompts = false`، والطلب ما زال يشترط فعل مستخدم). وفي عائلة Chromium **لا تُقبل نافذة طلب الصلاحية آليًا** (`evidence/T-1.4`)، فقيس ما بعد المنح على نسخة مشتقة من `dist/chromium` بإضافة `https://api.github.com/*` إلى `host_permissions` (ممنوحة عند التثبيت)؛ والحزمة المشحونة نفسها قيس عليها «قبل المنح». والمنح بنقرة فعلية في عائلة Chromium «لم يُجرَ آليًا».

## حدود معلنة

1. **عبارات صندوق الدمج**: «Review required» و«This branch has conflicts that must be resolved» رُصدتا في T-0.3؛ أما «Merging is blocked» و«Changes requested» و«out-of-date with the base branch» فعبارات واجهة GitHub الشائعة، تُطابق حرفيًا ولم تُثبَّت على صفحة حية مسجَّلة (`T-10.1`).
2. **قيم `mergeable_state`**: لا تسردها وثيقة REST؛ فُسِّرت بما يقابلها في `MergeStateStatus` الموثقة في GraphQL، ورُصد منها في T-0.3 `clean` و`unstable` و`dirty` و`unknown`. وأي قيمة أخرى تُعرض كما هي ولا تُفسَّر.
3. **الإلزامي من API**: سياقات `branches/{base}` في حماية الفرع؛ وقواعد rulesets قد تفرض فحوصًا لا تظهر هناك، فالفحص غير المذكور «لا يُعرف» لا «اختياري» (لا يُبنى عليه مانع ولا نفي مانع).
4. **حالة الخلفية في الذاكرة**: الحد وذاكرة ETag في ذاكرة الخلفية، وتعود فارغة بإيقاف service worker؛ فيُعاد تعلّم الحد من أول استجابة.
5. **صفحات github.com الحية**: لم يُجرَ التكامل عليها؛ الصفحات محفوظة حقيقية أو مكتوبة على بنية مرصودة، والردود مسجلة.
6. **حجم الحزمة**: `content.js` نما إلى نحو 858 KB و`background.js` إلى نحو 208 KB (بعد 782 و195 في الموجة D)؛ يُقاس في `T-10.1`.
