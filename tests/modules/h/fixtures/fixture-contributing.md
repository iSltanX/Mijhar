# Contributing to community

Thanks for your interest in improving **community**! This guide explains how to get your change merged.

## Getting started

1. Fork the repository and clone it locally.
2. Create a branch from `main` for your change.
3. Run `npm install` to install the dependencies.

## Development setup

- Use Node.js 22 or newer.
- Run `npm test` before you push.
- We use [Prettier](https://prettier.io) and ESLint; run `npm run lint` to check your code style.

```sh
# a fenced block must never be read as steps
1. not a step
- not a bullet
```

## Submitting a pull request

Please open an issue first to discuss any large change before submitting a pull request.

1. Make sure the tests pass.
2. Add tests for new behavior.
3. Open the pull request and link the issue it closes.

All contributors must sign the CLA before we can merge. Commits need a `Signed-off-by` line (DCO).

## Reporting issues

- Search the existing issues before filing a new one.
- Include steps to reproduce the problem.

## Translations

Translations are managed on [Crowdin](https://crowdin.com/project/community); please do not edit translated files by hand.
