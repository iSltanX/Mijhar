Read the docs here or here before you start.

Press Alt+H to toggle explain mode in the page.

Release v2.0.1-rc.3 shipped on Oct 22, 2026 with several direction fixes.

The build badge shows the current state of the main branch.

The side panel opens from the toolbar. It never changes what GitHub shows. Everything runs locally in the browser.

Quick start

  • Install the dependencies with pnpm install before building.
  • Configure the build target
    • Set the TARGET variable to chromium or firefox.

  1. Open the settings page and enable the modules you need.

OptionDescription
readerModeEnable the reader mode feature for long pages.
 
npm run build -- --mode firefox

Note: this tool never sends page content to any server.
