# مِجهَر (Mijhar): لوحة متابعة الخطة وطريقة تشغيلها

صفحة محلية تعمل دون أي خدمة مدفوعة، ولا تُرسل شيئًا إلى أي خادم.

## الفتح

- **الأسرع:** افتح `dashboard/index.html` مباشرة في المتصفح (نقرًا مزدوجًا) مرة واحدة، ثم اكتفِ بتحديث الصفحة بعد كل تقدم. البيانات محمّلة من `dashboard/data.js`، فلا تحتاج خادمًا.
- **إن أردت أن تعمل روابط ملفات الخطة (`.md`) بالنقر:** شغّل من جذر المشروع:

```bash
node tools/serve.mjs
```

ثم افتح `http://localhost:8765/dashboard/`. (الخادم بلا اعتماديات؛ وهو ما تستعمله معاينة Claude في `.claude/launch.json`.)

الخطان (Almarai وCairo) يُحمَّلان من Google Fonts عند توفر الاتصال؛ ودون اتصال تعمل الصفحة بخط النظام العربي.

## تبويب «الموجات»

التبويب الافتراضي. يعرض من مصدر واحد (`data/status.json` ← قسم `program`) كل الموجات ومراحلها، الموجة الحالية مفتوحة والبقية مطوية:

- المرحلة الحالية والخطوة التالية، ومراحل الموجة ومهام كل مرحلة بحالتها **مكتوبة**: لم تبدأ، جارٍ التنفيذ، متوقفة مع السبب، منفّذة وتنتظر الدمج (على فرع المرحلة)، مدمجة ومتحقق منها (في `main`).
- المودل لكل مهمة، مع إبراز الاستثناءات عن افتراضي الموجة، وسبب كل اختيار.
- بجانب كل مهمة منجزة: ما أُنجز، ومرجع الالتزام والفرع وتقرير الدليل.
- زرا «نسخ أمر البدء» و«نسخ أمر الدمج» لكل مرحلة: ينسخان نصًا تلصقه في المحادثة، ولا ينفّذان شيئًا.
- التفاصيل (الفحوص بحسب الأثر، والمراجعة، وما قبل البدء، والبنود المفتوحة) تُطوى وتُفتح عند الحاجة.

هذا التبويب يقرأ حالة الملف فقط ويتجاهل التعديلات المحلية المحفوظة في المتصفح. يحدّثه المنسّق (Claude) بتعديل `data/status.json` ثم `node tools/build.mjs`، فتتحدث الصفحة و`STATUS.md` معًا؛ ولا يُطلب منك تعديل أي حالة يدويًا.

## تحديث البيانات

مصدر البيانات الوحيد: `data/plan.json` (الخطة) و`data/status.json` (الحالات والأدلة والموجة) و`data/naming.json` (الأسماء). بعد أي تعديل فيها:

```bash
node tools/build.mjs
```

```bash
node tools/check.mjs
```

الأول يعيد توليد `ROADMAP.md` و`phases/` و`TRACEABILITY.md` و`DECISIONS.md` و`STATUS.md` و`NAMING.md` و`dashboard/data.js`. والثاني يفشل إن اختلفت البيانات عن `EXECUTION_PLAN.md` أو عن الملفات المولَّدة، أو تناقضت حالات الموجة مع مهامها (مثل مهمة «منفّذة» بلا مرجع التزام، أو «مكتملة» دون مرجع دمج للمرحلة).

## تعديل الحالات من الصفحة (التبويبات الأخرى)

- التعديل يُحفظ **في هذا المتصفح فقط** بزر «حفظ في هذا المتصفح»، ولا يغيّر أي ملف في المشروع.
- «مكتملة» و«اجتاز» و«فشل» تتطلب دليلًا (مسار تقرير في `evidence/` أو رابط).
- لتطبيق التعديلات: «الحالة: حفظ وتصدير» ← «تصدير status.json»، ثم ضع الملف مكان `data/status.json` وشغّل أمري التوليد والفحص أعلاه.
- «استيراد ملف حالة» يقرأ ملف `status.json` ويعرض ما يختلف فيه تعديلاتٍ محلية.
